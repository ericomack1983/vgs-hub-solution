# Turnkey Solutions Hub (prototype)

Static prototype webpage that lists turnkey solutions as client-facing cards (summary, key features, intended use case) with GitHub links and a pilot interest call-to-action.

## Open locally

- Open `index.html` in a browser.

## Customize

- Update solution content and GitHub repository links in `index.html` under the `<script type="application/json" id="solutionsData">` block.
- Update the pilot contact email in `app.js` (`SUPPORT_EMAIL`).
